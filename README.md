# Library API

REST API для управления библиотекой: книги, читатели и выдача книг. Спецификация описана в формате **OpenAPI 3.1.0** и предназначена для генерации клиентов, серверных заглушек и интерактивной документации (Swagger UI / Redoc).

## 🛠 Стек и формат
- **Спецификация**: OpenAPI 3.1.0
- **Формат данных**: JSON (`snake_case` для полей)
- **Базовый URL**: `https://my-best-library.com/api/v1`
- **Аутентификация**: Не требуется (для данного MVP)
