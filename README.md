# Backend Basics
Учебный проект для знакомства со структурой Python-проекта. Представляет собой приложение для сбора сводки по городу по 2 направлениям - курс валюты и погода. Есть специальные правила-флаги, которые помогают пользователю: рекомендации, стоит ли надевать теплую одежду или нет, и общая оценка цены валюты к рублю

## Что умеет?
- Сервис ходит в интернет через библиотеку requests
- Разбирает CLI аргументы
- Обрабатывает API-результат по особым правилам и возвращает статус-коды

## Требования
Python 3.12

## Запуск 

```bash
python main.py - без аргументов
python main.py --currency=EUR - с указанием валюты (по умолчанию USD)
python main.pt --city=Saratov - с указанием города (по умолчанию Moscow)
 ```
